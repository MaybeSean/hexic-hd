# Your Hexic HD game files go here

Copy the files from your own copy of the Xbox 360 game Hexic HD into this
folder. Nothing you put here is committed: everything except this README is
ignored by git.

The build needs:

| File(s) | What it is |
|---|---|
| `HexicDeluxe.swf` | The game itself |
| `KeyMap_HXIC.xml` | Controller and menu navigation map |
| `g.xml`, `k.xml` | English text |
| `de_g.xml`, `de_k.xml`, `es_*`, `fr_*`, `it_*`, `ja_*`, `ko_*`, `pt_g.xml`, `zh_*` | Other languages |
| `54.wma`, `Badback.wma`, `Belkell.wma`, `Cobblers.wma`, `Lubax.wma`, `Oilyn.wma`, `Slartisfgh.wma`, `Underlow.wma` | The soundtrack |
| `convectionui.ttf`, `xarialuni.ttf` | The Xbox fonts |

Any other files from the game, such as `default.xex`, can stay here; the build
ignores them.
